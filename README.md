# Bookflow SaaS (Next.js + Firebase)

Bookflow is a streamlined Appointment & Auto-Reminder SaaS for clinics, salons, and consultants. It offers an easy-to-use booking interface with automated SMS/WhatsApp notifications to reduce no-shows.

## 🛠 Tech Stack
- **Frontend Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Backend & Database**: Firebase (Firestore, Auth, Cloud Functions)
- **Local Dev**: Firebase Emulator Suite

## 🚀 Local Setup

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Run the Next.js Client**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.
